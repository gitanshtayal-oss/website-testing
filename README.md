# The Bellweather Case

An interactive, candlelit manor-house mystery. Investigate a vanished jewel, decode a secret message, and unmask the culprit.

## Play

Open [`index.html`](index.html) in a modern web browser. The experience is a self-contained static page; no installation or build step is required.

## Project

- `index.html` — the mystery game, including its styles and interactive elements.

## Run locally

Clone or download this repository, then open `index.html` in your browser. You can also serve the files with any static web server.
